# 🎓 AI-Powered Placement Preparation Portal

The **AI-Powered Placement Preparation Portal** is a comprehensive, centralized web application built with the MERN stack to streamline and enhance the placement preparation journey for students. It unifies learning, assessment, performance tracking, and placement management into a single, intuitive ecosystem, solving the problem of fragmented tools and disparate preparation resources.

---

## 🌟 Key Features

### 🧑‍🎓 For Students
* **Integrated Coding Sandbox**: Practice algorithmic challenges in an embedded Monaco-powered editor with real-time compilation for Java, Python, C++, Javascript, and more. Features test case evaluation and submission history.
* **Aptitude Assessment Module**: Topic-wise practice tests covering Quantitative Aptitude, Logical Reasoning, Verbal Ability, Data Interpretation, and Core CS Fundamentals with immediate performance analytics.
* **Core Subject Mastery**: Structured guides and assessments for Data Structures, Algorithms, DBMS, OS, Computer Networks, OOP, SQL, Java, Python, C, and C++.
* **AI-Assisted Resume Builder & Analyzer**: Create professional resumes and get intelligent feedback on structural gaps, missing technical skills, and overall quality based on target job roles.
* **AI-Powered Mock Interviews**: Take dynamic technical, HR, and behavioral interviews customized to your target role, with instant feedback on readiness and readiness analysis.
* **Personalized Dashboard & PRI**: Monitor your holistic Placement Readiness Index (PRI), track learning milestones, upcoming contest schedules, and targeted job recommendations based on your profile.
* **Doubt Resolution & Alerts**: Seamless community discussion forums, combined with real-time notifications for jobs, tests, interviews, and coding contests.

### 💼 For Administrators & Faculty
* **Centralized Management Dashboard**: Track aggregated metric readiness, aptitude scores, interview assessments, and coding stats of all students.
* **Bulk Question & Job Management**: Effortlessly add and configure corporate placement drives, external contest problems, and manage company-specific question banks.
* **User & Analytics Tracking**: Monitor user lifecycles, manage platform usage, and execute data-driven placement training programs tailored to different candidate batches.
* **Encrypted Security**: Secured roles management (Student, Faculty, Admin) allowing layered operational authorizations, with encrypted passwords.

## 💻 Tech Stack
The ecosystem evaluates data via a state-of-the-art framework to ensure scalability, robust performance, and total security.
* **Frontend**: React.js, Vite
* **Backend**: Node.js, Express.js (RESTful APIs)
* **Database**: MongoDB (Mongoose ORM)
* **Authentication**: JSON Web Tokens (JWT) & Role-based Authorization
* **Key Integrations**: Monaco Code Editor, Socket.IO, Real-Time AI Endpoints

## 🚀 Getting Started

### Prerequisites
* [Node.js](https://nodejs.org/en/) (v16+)
* [MongoDB](https://www.mongodb.com/) (Local or Atlas)

### Installation
1. Clone the repository and install root dependencies (if any).
2. Open two separate terminals to start the client and server concurrently, or utilize root shortcut scripts.

#### Backend Setup
```bash
cd backend
npm install
# Ensure you configure your .env variables (MongoDB URI, JWT Secret, AI API Keys)
npm start
```

#### Frontend Setup
```bash
cd frontend
npm install
npm run dev
```
